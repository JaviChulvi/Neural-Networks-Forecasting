# Model code index

This folder contains the training code and notebooks by model family:

- `mlp/`: dense neural networks.
- `cnn/`: convolutional models.
- `rnn/lstm/`: recurrent LSTM models.
- `rnn/gru/`: recurrent GRU models.
- `mixtos/`: mixed architectures combining dense, convolutional and/or recurrent layers.
- `preprocessing/`: financial preprocessing notebooks and scripts used for the research part.

The final report outputs are gathered in `reports/` for easier review.
