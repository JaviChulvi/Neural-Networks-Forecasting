# Reports index

This folder gathers the outputs that are most relevant for the final PDF/presentation.
The original code and generated technical outputs remain in `model/`, `data/` and `backtesting/` so existing notebooks and scripts continue to work.

- `competition/`: model comparison for the competition part: MLP, CNN, RNN and mixed architectures.
- `preprocessing/`: financial preprocessing research: time bars, count bars, volume bars, dollar bars and generated sequence summaries.
- `backtesting/`: 2025 portfolio/backtesting outputs and strategy metrics.
